# Gemas Inifinitas

Juego de combinaciones hecho con HTML, CSS, JavaScript y Phaser 4.2.1.

## Cómo jugar

Abre `index.html` en un navegador con conexión a Internet para cargar Phaser desde jsDelivr. En pantallas táctiles, desliza un caramelo hacia uno vecino o toca ambos en secuencia; los botones de pausa, reinicio, menú y herramientas están preparados para tocarse. También admite ratón, teclado y gamepad. Las partidas no tienen temporizador ni límite de movimientos; al alcanzar cada objetivo puedes continuar al siguiente nivel sin un tope de niveles.

El récord y el tema seleccionado se guardan en `localStorage`. Si el navegador bloquea ese almacenamiento, puedes continuar temporalmente en memoria.
