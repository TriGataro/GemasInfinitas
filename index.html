Tema de colores

Cómo jugar

  • Intercambia gemas vecinas para formar líneas de 3 o más iguales.
  • Una línea de 4 crea una gema que explota su fila o columna. Una línea de 5 crea una gema que explota un área de 3 × 3.
  • Toca una gema y luego otra vecina, o arrástrala hacia la que quieras cambiar.
  • Teclado: flechas o W A S D para moverte, Espacio/Enter para seleccionar y luego una dirección para intercambiar.
  • Mando: cruceta o palanca, botón A para seleccionar, Start para pausar.
  • Atajos: P pausa · R reinicia · Esc menú.
  • Las combinaciones en cadena multiplican tus puntos.
